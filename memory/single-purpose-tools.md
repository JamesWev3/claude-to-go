On 2026-11-17, after building about 1,000 lines of git UI into Neovim, he concluded he was "trying to reinvent the wheel" with apps "built for a different purpose". He decided "a much better option would be to use a tool that exists already and only has one purpose". He's happy to "dual-wield" two apps. He thinks the split (code here, git there) may even help him.

**Why:** home-made layers bloat his setup and go unused ("barely ever using them").

**How to apply:** when he wants a capability outside a tool's main job, look for a focused existing app first, before plugins or custom code. See [[git-app-hunt]] and [[usable-before-deeper]].
